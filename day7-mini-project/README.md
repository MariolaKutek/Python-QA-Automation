# API Testing Project

## Description

This project demonstrates automated API testing using Python and pytest.

The project performs HTTP requests to the JSONPlaceholder API and validates responses.

## Features

- GET requests
- POST requests
- PUT requests
- PATCH requests
- DELETE requests
- Status code validation
- JSON validation

## Tech Stack

- Python
- requests
- pytest

## Installation

pip install -r requirements.txt

## Run Tests

python -m pytest -v
