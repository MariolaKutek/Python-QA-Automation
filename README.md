## My 14-Day Plan

### Days 1–2: Python Basics
- Learned: variables, lists, dicts, if / for, functions
- Task: Create a function that filters active users from a list of dictionaries and returns emails
- Folder: `day1-basics/`
- AI Prompt: `"Write a Python function that filters active users from a list of dictionaries and returns emails"`

### Days 3–4: API Basics
- Learned: requests library, GET / POST, JSON
- Task: Make requests to a sample API and validate responses
- Folder: `day3-api/`

### Days 5–6: API Testing with pytest
- Learned: pytest framework, assert statements
- Task: Write tests to verify:
  - Status = 200
  - Response time < 1s
  - User objects contain name and email
- Folder: `day5-tests/`

### Day 7: Mini Project
- Task: Fetch users from API, save to JSON, write tests
- Folder: `day7-mini-project/`
- Outcome: First small project combining Python and API testing

### Days 8–9: Debugging & AI Skills
- Learned: reading errors, fixing AI-generated code
- Task: Take code from ChatGPT, find bugs, fix them, document changes

### Days 10–11: Advanced Testing
- Learned: test parametrization, multiple scenarios, error handling
- Task: Test different user IDs, handle missing users (404)
- Folder: `day10-advanced/`

### Days 12–14: Final Project – API Testing Framework Lite
- Task: Build a lightweight API testing framework
- Features:
  - Fetch data from APIs
  - Test status, schema, and data correctness
  - Generate reports (print/log)
  - AI-assisted test generation (bonus)
- Folder: `day14-final-project/`
- Outcome: Showcase-ready project for my CV
